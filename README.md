# An Odyssey of Change
### UCSD Fall 2025

use `npm run dev` to run the code starting in `main.ts`
use `npm test` to run the tests

use `npx tsc --noEmit` to check typing (cannot be fixed automatically)

use `npx eslint 'src/**/*.ts'` to check linting errors (unused vars, best practices, etc)

use `npx eslint 'src/**/*.ts' --fix` to fix linting errors

use `npx prettier --check 'src/**/*.ts'` to check formatting issues

use `npx prettier --write 'src/**/*.ts'` to fix formatting checks
